# Original VGGT components: retained INT8 profiles and CameraHead PTQ

The retained-aggregator investigation separates normal inference timing from SDK operator diagnostics. The saved v80 complete-model receipt contains 64 group calls: SDK execution contributes 427.837 ms per pose, input submission 19.485 ms, output acquisition 3.611 ms and owned copies 2.251 ms. The outer aggregator interval after subtracting DINO is 485.966 ms; its remaining time also includes original token preparation, concatenations, normalization and guards. These scopes overlap and must not be added together. This evidence directs optimization toward execution inside the compiled graphs, rather than assuming host validation is the main cost.

The v82 profile probe executes the same four compiled INT8 groups on two frozen original inputs with SDK flags 8. Its eight profiles contain 1,231 rows per input: 1,218 NPU operators and 13 CPU input/output operators, with no reported internal CPU mathematical fallback. The 192 `exNorm` rows account for 22.79–25.01% of summed profile time; Q/K normalization contributes more than the width-1024 block normalization. Attention, transpose and reshape are also substantial. Norm, attention and FC1 rows report workload on one NPU core, while QKV and FC2 rows report three-core allocation. These are SDK workload labels, not continuous utilization measurements. All rows are labelled INT8, which does not independently prove integer arithmetic inside every fused operation. Independent group inputs and flags-8 profiling are diagnostic; these totals are not normal warm inference latency.

A proposed next experiment is an onboard Mali implementation of the original Q/K normalization, RoPE and complete scaled-dot-product attention tail as one operation. It would retain both original attention shapes, all queries/keys/values, original normalization parameters, position tables, scale and softmax. It requires captured original QKV values and references, exact producer/consumer quantization and layout information, and a benchmark including conversion, DMA import, coherence and ownership costs. This candidate is untested; neither speed nor numerical acceptance is established. The slower v81 GPU MLP experiment is not integrated. No host GPU is used.
