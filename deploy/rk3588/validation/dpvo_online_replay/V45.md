# v45 closed-query cache in the complete native replay

This optional DPVO research replay adds the frozen [v44 cache-hit closed query](../dpvo_cache_closed_flag/README.md) to the [v44 native-input replay](V44.md). It replaces an unused native cache before any SDK context exists. Only the live-hit expression in `BoundedContextCache._get` changes: `session_closed(session)` reads `session._metrics['closed']` under the session lock instead of calling the full `session.metrics()['closed']`. Cold initialization, memory budgets, lifecycle metrics, native packing, SDK calls and output copies retain their frozen implementations.

The nine models, original 94 parameters, M16/L4/R8/O4/KF2 policy, RNG sequence, complete-source grouping, explicit Torch D1 startup probe, correlation, BA and EOF remain unchanged. The driver preserves the parent's frame loop, Update routing and cleanup AST. Default VGGT remains unchanged; this research does not add ORB/LK/PnP.

The RK3588S execution completes 192 observations and 158 fresh poses, with 52.561283 s active replay: **3.006015 Hz** fresh throughput and **338.112205 ms** software admission-to-publication P95. Another 2.421033 s covers EOF; its 12 Updates and 24 BA steps are offline work. Peak process RSS is 515.585938 MiB on a 16 GB board. This serial, unpaced replay does not measure physical camera capture or queued-frame age, and its separate thermal history does not establish a controlled whole-system speedup.

The independent saved parity audit finds all 192 non-clock results and 55 saved array pairs, including 14 final-state arrays, bitwise equal to v44. RNG metadata and EOF agree. The separate trajectory evaluator uses the actual schemas with no compatibility mapping: common-fresh ATE/rotation RPE/translation RPE remain approximately **0.019683 m / 1.793720 degrees / 0.036012 m**, still outside the 10–20% quality target relative to full-resolution FAST. Historical original-FP32 rejection, workload quality rejection and unvalidated 20 Hz/map/endurance/8 GB status remain. `candidate_accepted` stays false. Actual internal operators are not asserted to be all NPU.

## Integration and prerequisites

`v45_online_factory.open_board_online_from_index` wraps the frozen v44 factory with the same config. It adds these six config fields:

```python
v44_factory, v44_factory_sha256,
closed_flag_helper, closed_flag_helper_sha256,
closed_ab_receipt, closed_ab_receipt_sha256
```

The required closed-query AB prerequisite is the completed 24-call same-state run with SHA `1a2132b70849fe823e3d85617d588f2d1dd5626326adfa4c14c0e718d2f7faf4`: both routes have 56 SDK calls/releases, six closed contexts and bitwise-equal saved outputs. The integration retains all previous native build, conversion, query, single/full AB and model/compile prerequisites. It shares the packing library across contexts; each initialized context performs its own native commands 8/10 queries. Unknown shapes or failed guards stop execution without full-Update CPU fallback.

The driver adds `--v44-online-driver` and `--diagnostic-allow-closed-flag`. All three explicit flags are required: this flag, `--diagnostic-allow-native-fp16` and `--diagnostic-allow-fp32-rejected`. The factory source SHA is `0e573fd8d917b59bcdd843d66db0e8136cef8c076b6452595bec61251329af56`; the driver SHA is `d51b96d4dc3da24e4f0d284d539593020dd6e14b5ad3f974b81256e460568a2c`.

## Board reproduction

The following uses the actual deployment layout with a new output directory. Obtain models, original checkpoint, data, native libraries, SDK/header and all prerequisite receipts separately, then verify their recorded hashes. These board-local paths are examples, not repository installation defaults. Before replay, make a **new encoder config copy** outside the new output directory and set its `log_directory` to `/mnt/vggt-data/vggt-slam2/experiments/NEW-v45-replay/encoder-native`. Compute the SHA of that edited JSON and replace `SHA256_OF_NEW_ENCODER_CONFIG` below. Reusing the archived r1 encoder config would write to its old native-log directory and can fail; its original SHA is not valid for the new copy. Do not create the replay output directory in advance. When relocating any other config paths, recompute those JSON config hashes too; do not change pinned model/source bytes. `--help` lists every required argument.

## Independent transport-record audit

`audit-v45-closed-native-online-records.py` checks the new schema, flags, frozen cache-only AST proof and actual AB prerequisite before privately importing the frozen v44 auditor. Its compatibility view maps only `schema`, `closed_flag_optimization_added` and `online_catalogue_provenance.closed_flag_optimization_added` for that parent audit. Ledger, source, input and output records are unchanged. The actual run JSON is never rewritten. This mapping is separate from the unmapped saved-array parity and trajectory audits.

The first saved-record audit passes: 965 Update calls/releases, 2,895 native pack descriptors, 54 attribute queries across nine contexts, and 192 encoder calls/releases are cross-checked. All contexts close with zero current model/DMA bytes and no cleanup errors. Model files total 66,123,629 bytes; their host buffers total 66,123,638 bytes including nine terminating bytes. Peak reported DMA is 79,982,592 bytes. Per-call native payloads were not saved for reconversion, and host record checks do not independently rehash board binaries or prove original-Torch numerical acceptance. Nested SDK timings are not additive to complete replay time.

```sh
python -B deploy/rk3588/validation/dpvo_online_replay/audit-v45-closed-native-online-records.py \
  --run-dir /path/to/v45-replay \
  --run-sha256 213eb55d28325cdc8ddbc18fb561a62da3c055482d2b9915c293d4c5154f7776 \
  --compile-index /path/to/nine-model-index.json --output /path/to/NEW-review.json
```
