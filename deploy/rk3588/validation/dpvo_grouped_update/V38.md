# Complete saved-graph RKNN diagnostics

The three original M48 states now run through all actual degree groups, using
14 compiled shapes and the unchanged v37 transport. This is optional DPVO
research; no recurrent state is committed and the default VGGT path is unchanged.
All strict original-CPU comparisons still reject the candidate.

`run-v38-grouped-full-board.py` requires the original export manifest, capture,
compile index, frozen SDK helpers and adapter, and the locally licensed SDK
header/library. Pass `--diagnostic-allow-fp32-rejected` explicitly. Its board guard
checks Linux/aarch64/RK3588/S before loading native SDK code. Use separate absent
output directories for ordinary execution and `--collect-perf-detail`.

Normal execution uses three full calls for each of observations 13, 127 and 191;
each has one cold and two warm samples. Profiling uses one full call per state.
The actual cache limit was 14 contexts, 256 MiB model buffers and 512 MiB DMA.
The smaller supported context bound was not measured. Model compilation here
was nonquantized, and actual neural execution was exclusively on the board.

Full wall time includes immutable snapshots, validation, packing, context
initialization when needed, SDK I/O, owned copies, release, domain checks and
full original-order scatter. Captured-input preparation, output hashes, reference
statistics and saves are outside that timer. Cold context initialization's
model reads and source verification are inside it. Nested group/cache/init
times must not be added twice.
These fixed-state calls omit tracking, BA and feedback; no fresh-pose rate can
be inferred from them.

`run-v38-B8-input-AB-board.py` is a separate same-context AB/BA/AB diagnostic of
FP32 versus prepacked FP16 typed input. Both use `pass_through=0`; neither uses
zero-copy. NumPy FP16 prepacking was slower, while all returned outputs were
bitwise unchanged. Keep the original FP32 transport.
