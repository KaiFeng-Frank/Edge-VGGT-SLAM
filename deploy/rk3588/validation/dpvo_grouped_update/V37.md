## Tools and boundaries

- `export-v36-grouped-update-board.py`: board-only real grouped Torch/ORT validation and ONNX export from frozen captures. Required hashes identify the original capture, source and weights. Same-degree complete source groups form true batch items; no padding, dropping or split reductions.
- `compile-v37-grouped-update.py`: host compilation with `do_quantization=False` only. Select `--model-key B8_D8_M48`, pin `--manifest-sha256`, and supply a new `--output-dir`. Actual rejected export ancestry requires `--diagnostic-allow-fp32-rejected`; that flag never adopts a candidate.
- `v37_grouped_contracts.py` and `v37_grouped_rknn.py`: queried-layout contracts, owned CF/NHWC transport, guarded release and bounded context cache. Fake tests cover shuffled full restoration, late failure and stale snapshots. The actual B8 diagnostic does not exercise the multi-shape cache.
- `run-v37-grouped-initial-board.py`: board-only initial full-state normal/profile runner. `--help` lists external model, captured arrays, manifest, frozen compiler/runtime and ABI paths. It saves CF and independently restored original-order arrays, retains FP32 failures, and never commits recurrent state or invokes BA.
- `audit-v37-grouped-update-export.py`: saved-array/static ONNX review, no forward. It verifies parameter-byte coverage, complete input groups, inverse ordering and every original gate.

Run normal/profile in distinct directories and retain failed receipts. SDK `want_float=1` converted output lengths must equal FP32 logical bytes even when native stride storage is larger. Actual input B8 is NHWC; relabeling untransposed CF memory is invalid.
